# Architecture Decision Records

One file per decision. Numbered, never renumbered, never deleted.

Status is one of:

```text
PROPOSED    Written up, awaiting user confirmation. Nothing built against it.
ACCEPTED    Confirmed. Code may depend on it.
SUPERSEDED  Replaced. The replacing ADR is named in the header.
```

A PROPOSED ADR is not a decision. Do not build against one.
